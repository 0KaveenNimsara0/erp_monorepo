## Debugging Templates & Log Format

When recording AI debugging sessions, follow this standard structure:

```markdown
### Session #[ID]: [Topic / Issue Title]

- **Prompt / Request**: Brief description of the issue or feature.
- **Root Cause**: Analysis of why the problem occurred.
- **Solution Executed**: Summary of file changes and refactoring steps.
- **Verification**: Tests run and verification results.
```
